# Deploying Melody Maestro to GitHub Pages

This guide walks through every step to get the game running at
`https://samperk1.github.io/melody-maestro/`.

---

## What you need

- Godot 4.x installed (the same version you used to build the game)
- Git and a terminal
- A GitHub account (already set up — remote is `https://github.com/samperk1/melody-maestro.git`)

---

## Step 1 — Install the Godot Web export templates

The web export templates are a one-time download inside Godot.

1. Open the project in the **Godot Editor**.
2. Go to **Editor → Manage Export Templates…**
3. Click **Download and Install** for your Godot version.
4. Wait for it to finish, then close the dialog.

---

## Step 2 — Export the game as HTML5

1. In Godot, go to **Project → Export…**
2. Click **Add…** and choose **Web**.
3. Set the **Export Path** to:
   ```
   docs/index.html
   ```
   (This puts all the exported files straight into the `docs/` folder.)
4. Leave everything else at the defaults.
5. Click **Export Project** (not "Export PCK").
6. When it finishes you should have these files in `docs/`:
   ```
   docs/
   ├── coi-serviceworker.js   ← already here (do not overwrite)
   ├── index.html             ← generated by Godot
   ├── melody-maestro.pck     ← game data
   ├── melody-maestro.wasm    ← compiled game code
   └── melody-maestro.js      ← Godot loader
   ```

---

## Step 3 — Add the service worker to index.html

Godot 4 web exports need `SharedArrayBuffer`, which requires two special HTTP headers.
GitHub Pages cannot set those headers, so `coi-serviceworker.js` adds them via a browser
service worker. You need to wire it into the exported `index.html`.

Open `docs/index.html` in a text editor and find the **very first `<script>` tag** near the
top of the file. Add the following block **before** that tag:

```html
<!-- Cross-Origin Isolation — required for Godot 4 web exports on GitHub Pages -->
<script src="coi-serviceworker.js"></script>
```

Save the file.

> **Tip:** You only need to do this once. If you re-export the game later, Godot will
> overwrite `index.html`, so you will need to add this line again each time.

---

## Step 4 — Push to GitHub

Run these commands in the project root:

```bash
git add docs/
git commit -m "Add web export for GitHub Pages"
git push origin main
```

---

## Step 5 — Enable GitHub Pages

1. Go to **https://github.com/samperk1/melody-maestro**
2. Click the **Settings** tab.
3. In the left sidebar click **Pages**.
4. Under **Source**, set:
   - **Branch:** `main`
   - **Folder:** `/docs`
5. Click **Save**.

GitHub will show you a URL — it usually takes 1–2 minutes to go live.

Your game will be at:
```
https://samperk1.github.io/melody-maestro/
```

## Browser compatibility notes

| Feature | Chrome / Edge | Firefox | Safari |
|---|---|---|---|
| Game loads | Yes | Yes | Yes |
| MIDI keyboard | Yes | No | No |
| Microphone input | Yes | Yes | Partial |
| On-screen keyboard (mouse) | Yes | Yes | Yes |

MIDI input uses the Web MIDI API, which Chrome and Edge support natively. Firefox users
will need to use the on-screen keyboard or microphone input instead.

---

## Re-exporting after code changes

Every time you change the game and want to update the live version:

1. Export again from Godot (**Project → Export → Web → Export Project**) to `docs/index.html`.
2. Clean up the extra files Godot leaves in `docs/`:
   ```bash
   rm -f "docs/Melody Maestro.html" docs/*.import
   ```
3. Re-add the service worker line:
   ```bash
   sed -i 's|<head>|<head>\n\t<script src="coi-serviceworker.js"></script>|' docs/index.html
   ```
4. Push:
   ```bash
   git add docs/ && git commit -m "Update web build" && git push origin main
   ```

## Troubleshooting

**Game shows a grey screen / spinner that never loads**
: The service worker line is missing from `index.html`. Re-add it (Step 3).

**"SharedArrayBuffer is not defined" in the browser console**
: Same as above — the COOP/COEP headers are not being applied.

**Service worker not updating after a re-export**
: Open Chrome DevTools → Application → Service Workers → click **Unregister**, then reload.

**Game loads but MIDI keyboard is not detected**
: MIDI only works in Chrome and Edge. Also make sure your OS recognises the MIDI interface before launching the browser.
